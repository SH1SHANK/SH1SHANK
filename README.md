## Projects

### [Attendrix](https://attendrix.app) · `live`
Academic management platform for NIT Calicut — attendance tracking, smart scheduling, gamified economy, challenge systems, and a Telegram bot (Lumen).

`Flutter` `Dart` `Supabase` `PostgreSQL` `GitHub Actions`

→ Production-grade · 35-table schema · RLS-enforced multi-role access · Full CI/CD pipeline

&nbsp;

### [Pytrix](https://github.com/sh1shank/pytrix)
Serverless browser-based Python practice platform — no backend, no installs, executes entirely in-browser via Pyodide.

`Next.js` `TypeScript` `Pyodide` `Monaco Editor` `IndexedDB`

→ SM-2 difficulty calibration · Dual LLM provider layer (local + cloud fallback) · Fully offline

&nbsp;

### [Promptium](https://github.com/sh1shank/promptium)
Chrome extension for AI workflow automation across ChatGPT, Gemini, Perplexity, and Copilot with Arc browser compatibility.

`TypeScript` `Chrome Extensions` `Shadow DOM` `Gemini API` `OpenRouter`

→ Platform-agnostic prompt injection · Cloud provider switching · Chat export pipeline

&nbsp;

### [markdrop](https://github.com/sh1shank/markdrop)
Local desktop converter (PDF / PPTX / DOCX → Markdown) — fully offline, no LLM, no cloud dependency.

`Python` `PySide6` `Tesseract OCR` `pdfplumber` `MarkItDown`

→ Three-stage PDF post-processing · Batch folder input · Live Markdown preview

&nbsp;

### [Studytrix](https://github.com/sh1shank/studytrix)
Offline-first academic PWA with semantic file search and smart auto-collections.

`Next.js` `TypeScript` `IndexedDB` `Web Workers` `Google Drive`

→ k-means smart collections · Cosine similarity semantic search · File System Access API
